# Sample Images

Place corrosion test images here for development and demos.

## Recommended sources

- [Roboflow Corrosion Dataset](https://universe.roboflow.com/roboflow-100/corrosion-bi3q3) — download sample images from the dataset
- Google Images search: `corrosion steel pipe`
- Any real-world corrosion photo (JPG, PNG, WEBP)

## Naming convention

```
corrosion_<descriptor>.jpg
e.g.:
  corrosion_pipe_heavy.jpg
  corrosion_wall_light.jpg
  corrosion_metal_moderate.jpg
```

## Demo flow

The demo uses whatever image you upload through the UI.
Add a few images here and reference them during demos.
